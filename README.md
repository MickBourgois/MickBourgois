## What I build

### 🎙️ [Scrybecast Studio](https://scrybecast.studio)

My SaaS for podcasters and podcast studios. Turn recordings into transcripts, show notes, blog articles, social posts and newsletters — with audio uploads, RSS imports and live transcription.

Live markers and EDL exports also help bridge the gap between recording and editing. Scrybecast Studio is the next version of Scrybecast, originally built with Bubble and Make.

My independent studio for product development, AI integrations and automation. I build new products, improve existing applications and help teams adopt Claude Code through hands-on work and practical training.

The goal: go beyond the demo and deliver software that can be used, maintained and improved.

- **Start with the problem.** Understand the people and the workflow before choosing the tools.
- **Build with AI, keep human judgment.** Claude Code accelerates implementation; product decisions, code review and validation remain essential.
- **Own what happens after launch.** Deployment, debugging, maintenance and iteration are part of building the product.
